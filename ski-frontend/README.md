# 黑龙江滑雪场管理系统前端

本项目是“黑龙江滑雪场管理系统”的 Vue 3 前端，采用前后端分离结构，与 Spring Boot 后端配套使用。页面分为游客端和管理端，功能覆盖雪场资源、滑雪服务、订单、运营信息、安全保障及员工管理，适合作为本科毕业设计的演示前端。

## 技术栈

- Vue 3、Vite
- Vue Router、Pinia、Axios
- Element Plus
- ECharts

## 功能模块

### 游客端

- 首页综合展示、雪场导览、公告资讯
- 雪票购买、雪具租赁、课程报名和教练展示
- 游客注册与登录
- 个人资料、订单支付/取消/归还
- 意见反馈提交与回复查看

### 管理端

- 经营数据看板
- 滑雪场、雪道、设施管理
- 雪票、雪具、课程、教练和订单管理
- 天气雪况、公告和游客反馈管理
- 设施维护与安全巡检管理
- 员工账号管理

## 本地运行

先启动后端服务，确认其运行在 `http://localhost:8081`，然后在当前目录执行：

```powershell
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。Vite 会把 `/api` 请求代理到后端，因此本地开发不需要单独配置 CORS。

演示账号：

- 游客端：`student / 123456`
- 管理端：`admin / 123456`

## 构建

```powershell
npm run build
```

构建结果输出到 `dist` 目录。

## 项目目录

```text
src/
├─ api/          后端接口封装
├─ components/   公共展示组件
├─ layouts/      游客端和管理端布局
├─ router/       页面路由与登录守卫
├─ stores/       登录状态管理
├─ styles/       全局样式
├─ utils/        请求、字典和格式化工具
└─ views/        游客端与管理端页面
```

后端项目名为 `ski-backend`
